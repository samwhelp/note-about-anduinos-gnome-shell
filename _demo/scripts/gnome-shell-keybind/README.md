

# gnome-shell-keybind




## Link

* https://github.com/samwhelp/note-about-anduinos-gnome-shell/blob/gh-pages/_demo/scripts/gnome-shell-keybind/gnome-shell-keybind.sh
* https://raw.githubusercontent.com/samwhelp/note-about-anduinos-gnome-shell/refs/heads/gh-pages/_demo/scripts/gnome-shell-keybind/gnome-shell-keybind.sh




## Prepare

> install wget and curl

``` sh
sudo apt-get install wget curl
```




## Usage

> run

``` sh
bash <(curl -L https://raw.githubusercontent.com/samwhelp/note-about-anduinos-gnome-shell/refs/heads/gh-pages/_demo/scripts/gnome-shell-keybind/gnome-shell-keybind.sh)
```

> or run

``` sh
bash <(wget -q https://raw.githubusercontent.com/samwhelp/note-about-anduinos-gnome-shell/refs/heads/gh-pages/_demo/scripts/gnome-shell-keybind/gnome-shell-keybind.sh -O - )
```


> or run

``` sh
bash -c "$(curl -fsSL https://raw.githubusercontent.com/samwhelp/note-about-anduinos-gnome-shell/refs/heads/gh-pages/_demo/scripts/gnome-shell-keybind/gnome-shell-keybind.sh || wget -q https://raw.githubusercontent.com/samwhelp/note-about-anduinos-gnome-shell/refs/heads/gh-pages/_demo/scripts/gnome-shell-keybind/gnome-shell-keybind.sh -O - )"
```


> or run

``` sh
bash -c "$(wget -q https://raw.githubusercontent.com/samwhelp/note-about-anduinos-gnome-shell/refs/heads/gh-pages/_demo/scripts/gnome-shell-keybind/gnome-shell-keybind.sh -O - || curl -fsSL https://raw.githubusercontent.com/samwhelp/note-about-anduinos-gnome-shell/refs/heads/gh-pages/_demo/scripts/gnome-shell-keybind/gnome-shell-keybind.sh)"
```
